Cloud Outfitters: .NET observability on AWS

.NET 10 · AWS Distro for OpenTelemetry auto-instrumentation · Amazon CloudWatch Application Signals

1Shopper places an order

Requests reach the storefront through the load balancer. Application tasks stay in private subnets.

2Storefront calls the API

ECS Service Connect lets the storefront call the API by name. Trace context flows with every call.

3Auto-instrumentation

ADOT loads at startup through environment variables. The app code uses only built-in .NET APIs.

4Agent sidecar ships telemetry

Each task's CloudWatch agent sends traces and metrics to CloudWatch and X-Ray. Calls to S3 and Secrets Manager are traced automatically.

5One place to observe

Application Signals, traces, metrics, and logs come together on the CloudWatch dashboard.

The same app and instrumentation also run on a developer laptop or Amazon EC2 (Windows). Only environment variables change.
